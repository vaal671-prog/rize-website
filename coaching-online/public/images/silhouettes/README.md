# Silhouette images

Drop your generated images in this folder using these **exact filenames** —
the questionnaire (`lib/questionnaire-data.ts`) already references these
paths, so nothing else needs to change once the files exist here.

Until a file exists, that option shows a dashed placeholder box with its
expected filename instead of breaking the page.

Recommended: portrait crop, ~3:4 aspect ratio, consistent lighting/background
across the set of 10 so the grid feels cohesive.
